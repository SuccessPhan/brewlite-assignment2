BrewLite v1.0.0 là bản phát hành production đầu tiên của Assignment 2: luồng đặt món end-to-end chạy trên môi trường truy cập được qua HTTPS, triển khai tự động bằng pipeline CI/CD.

## Truy cập

| | Địa chỉ |
|---|---|
| Web (PWA) | https://brewlite-nhom10.vercel.app |
| API | https://brewlite-api-gb4h.onrender.com |
| Health check | https://brewlite-api-gb4h.onrender.com/health |

API chạy gói miễn phí của Render, ngủ sau 15 phút không có truy cập; lần gọi đầu mất khoảng 50 giây để thức dậy.

Tài khoản khách demo: `demo@brewlite.vn` / `Brewlite123`, hoặc tự đăng ký (được tặng 1.250 điểm). Tài khoản nhân viên quầy và quản lý trên production dùng mật khẩu riêng, gửi kèm bài nộp, không ghi trong repository. Thanh toán VNPay dùng môi trường sandbox (thẻ test NCB trong README), không trừ tiền thật.

## Chức năng

- **Khách hàng**: xem menu, tìm món không dấu; chọn size S/M/L, mức đường, mức đá, topping; giỏ hàng giữ khi tải lại trang; đăng ký, đăng nhập JWT; báo giá theo CSDL trước khi đặt; nhận tại quầy hoặc giao tận nơi; mã giảm giá; thanh toán VNPay sandbox hoặc điểm BrewLite; thanh toán lại khi thất bại; theo dõi đơn tự cập nhật; lịch sử đơn và giao dịch, đối soát với VNPay; tích điểm, đổi quà; thông báo; món yêu thích.
- **Nhân viên quầy**: hàng đợi đơn đã thanh toán, chuyển PAID → PREPARING → READY → COMPLETED; huỷ đơn chưa pha kèm lý do (tự hoàn kho, hoàn điểm, đánh dấu cần hoàn tiền).
- **Quản lý**: tổng quan doanh thu; thực đơn và giá; mã giảm giá; tài khoản khách (khoá, mở khoá); phản hồi; nội dung trang; kho nguyên liệu, phiếu nhập, công thức.
- **PWA**: cài lên màn hình chính, mở toàn màn hình; mất mạng thì hiện trang báo.

## Nghiệp vụ và độ tin cậy

- Máy trạng thái đơn hàng chặn mọi chuyển trạng thái sai (409).
- Thanh toán idempotent theo `Idempotency-Key`: gửi lặp, kể cả đồng thời, chỉ tạo một giao dịch.
- Kết quả VNPay chỉ được ghi nhận khi đúng chữ ký HMAC-SHA512 và đúng số tiền, ghi đúng một lần dù Return URL và IPN tới cùng lúc.
- Tồn kho trừ trong transaction với optimistic locking: đặt đồng thời không bán vượt kho.
- Đơn chưa thanh toán quá 30 phút tự huỷ, trả món về kho.

## Bảo mật

Mật khẩu băm bcrypt; JWT, phân quyền 3 vai trò (khách, nhân viên quầy, quản lý) đọc từ CSDL mỗi request; validate đầu vào, từ chối trường lạ; giới hạn request theo IP (tính đúng IP khách sau proxy); header bảo mật, HTTPS; tài khoản CSDL của ứng dụng chỉ đọc/ghi dữ liệu, ràng buộc CHECK; CSDL production chặn mọi kết nối từ Internet; secret chỉ nằm trên GitHub Secrets, Render, Vercel.

## Hạ tầng và quy trình

- CI chạy khi mở pull request: Install → Lint → Unit Test → Build → Integration → E2E. `main` được bảo vệ: cần 1 người duyệt và 3 check bắt buộc đều đạt.
- CD khi merge vào `main` hoặc tạo tag: build Docker image gắn tag commit SHA và phiên bản → đẩy GitHub Container Registry → deploy API lên Render → deploy web lên Vercel → smoke test → tự rollback khi lỗi.
- CSDL tạo bằng Prisma Migrate, chạy `prisma migrate deploy` khi khởi động (chỉ thêm, không xoá dữ liệu); seed chạy lại không trùng.
- Tài liệu: [docs/deployment.md](https://github.com/SuccessPhan/brewlite-assignment2/blob/v1.0.0/docs/deployment.md) (cài đặt, phát hành, rollback).
